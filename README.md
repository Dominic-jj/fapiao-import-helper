# 发票明细导入助手

为电子税务局开票准备商品明细的 Windows 本地桌面工具。快速打字录入商品，查询并确认商品税收分类编码，导出标准 Excel，再通过官方页面的“明细导入”批量导入。

**录入商品 → 校对与选税编 → 导出 Excel → 官方明细导入 → 开具、打印。**

适合商品较多、需要反复录入和查找税编的场景。录入与校对在本地完成，减少官方页面的逐行操作；实际发票开具和打印仍在官方系统完成。

[Git 提交记录](https://github.com/Dominic-jj/fapiao-import-helper/commits/main/) · [下载页面](https://github.com/Dominic-jj/fapiao-import-helper/releases) · [MIT 许可证](LICENSE)

## 启动程序

运行环境为 Windows 10/11，需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

### 源码运行

安装 Python 3.10 或更高版本后，在项目目录执行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

依赖安装完成后，日常启动只需运行 `python main.py`。

### Windows 程序包

直接双击 `FapiaoImportHelper.exe`，无需安装 Python，也无需额外的程序资源文件夹。

当前为预览阶段，尚无正式 Release 安装包；实际官方明细导入验收完成后再发布。

## 录入、校对和导出

### 1. 逐行输入商品

每行一条明细，支持两种空格录入格式：

```text
名称 单位 数量 单价
规格 名称 单位 数量 单价
```

例如：

```text
笔记本 本 5 8
A4 复印纸 包 2 25
M6 铜螺丝 个 2 3
```

按 **Ctrl+Enter** 或点击“解析明细”，进入可编辑表格。

- 单价、数量、单位从右往左读取；开头的词像规格时拆入规格栏，其余作为名称。
- 无规格时直接省略，不需要占位符。
- **空格录入时，规格内部不能再加空格。** 需要“铜 M6”这样的规格，可在解析后编辑规格栏，或使用 CSV：`铜螺丝,铜 M6,个,2,3`。
- 支持从 Excel 粘贴 Tab 分列数据，或粘贴 CSV。四列顺序是“名称、单位、数量、单价”；五列顺序是“名称、规格、单位、数量、单价”，空规格列保留。

核对解析后的名称、规格、单位、数量和单价。金额由数量乘以单价计算，并取到两位小数。

### 2. 查询并确认税编

在商品行的税编搜索框输入商品名、分类名、简称或编码，选择符合实际商品的具体分类。候选可用方向键切换、Enter 选择、Esc 关闭。

自动建议需点击“确认建议”。材质或用途不明确时，补充商品资料或手动查询后再选定；未确认、无效或汇总分类编码不能导出。

“保存税编确认”只保存已确认记录，供后续相同名称和兼容属性的商品复用。重新匹配保留人工选择；名称变化会重新匹配，关键规格或单位变化需要重新核对，数量或单价变化只重算金额。

### 搜索结果不满意时：浏览完整税表

点击顶部 **“浏览税编表”**，或商品行内的 **“浏览表”**：

1. 左侧选择大类，中间点击“查看下级”逐层浏览。
2. 搜索名称、分类简称、说明或税号；搜索范围为当前分类及下级，返回“全部分类”可搜索全表。
3. 点击条目，在右侧查看完整分类名称、税号、分类路径和说明。
4. 查看具体商品后，可复制税号作为人工核对参考。这个面板只负责查询，不修改或确认任何商品行。

勾选“只看具体商品”可隐藏汇总项。完整税表分页显示，不受自动推荐候选数量限制；汇总分类只能浏览，具体税号可复制。

### 3. 核对设置并导出 Excel

在“我的商品库与导出设置”中核对默认税率与单价口径：

- 默认税率用于新明细，已有明细的税率可逐行修改。
- 明确单价是“含税”还是“不含税”；程序保留该口径，官方导入时必须选择相同选项。

完成校对后点击“导出 Excel”。程序会提交表格的最新编辑，并拦截未解析行、非法数字及未确认或无效税编，生成标准 `.xlsx` 明细文件。

## 导入官方开票页面

以下以广东省电子税务局页面为例，官方界面可能调整。本工具是独立第三方本地助手。

登录后进入蓝字发票开具页面，在“开票信息”区域点击 **“明细导入”**。

![官方开票信息区域及明细导入按钮](resources/screenshots/official-entry-panel.png)

在导入面板点击“选择文件”，选择刚导出的 Excel，设置与程序一致的含税/不含税口径。核对导入结果、行数、商品编码、金额和税率，确认无误后再完成官方开具和打印。

## 我的商品库与草稿

### 使用自己的历史商品

在“我的商品库与导出设置”中选择历史目录，点击“保存并重新读取”；以后启动时自动加载。页面显示读取数量、冲突及忽略原因，可点击“打开目录”查看原文件。

使用本工具导出的标准明细 Excel，或与其格式一致的历史文件。其他工作表或表头布局会被跳过并提示原因，历史原文件不会被改写。

个人确认库优先推荐，普通历史先作为建议，确认后可保存复用。同名不同属性或不同编码的记录保留供核对，不静默覆盖。

默认使用通用模式；主要经营五金、电工或水暖商品时，可启用对应行业词库辅助理解品名。

当前版本仅使用本地历史、确认库、别名、行业词库和税表进行匹配，不再提供 AI 辅助或 API Key 配置。

### 自动保存与数据位置

原始输入和有效表格编辑会自动保存为本地草稿，重新启动后可恢复。税表变化时，需要重新核对分类。

草稿、偏好和个人确认库保存在 `%LOCALAPPDATA%\FasterTax\`，为兼容旧版本保留这个目录名。其中草稿为 `draft.json`，偏好为 `settings.json`，个人确认库位于 `resources/mappings/` 子目录。程序升级不会用内置示例覆盖个人确认库。

公共程序包只携带页面、模板、税表和公共词库，不包含作者个人历史、映射或密钥。

## 开发、构建与贡献

### 构建 Windows 程序包

```powershell
python -m pip install -r requirements.txt "pyinstaller>=6,<7"
python -m PyInstaller --noconfirm --clean --distpath build --workpath "$env:TEMP\FapiaoImportHelper-build" packaging/FasterTax.spec
```

产物直接放在 `build/FapiaoImportHelper.exe`，分发这一个文件即可。构建缓存使用系统临时目录，`build/` 只存放可运行的 exe。

### 验证与反馈

```powershell
python -m pip install -r requirements.txt "pytest>=8,<10"
python -m pytest -q
python tests/desktop_smoke.py
```

桌面检查使用隔离用户目录和真实 Windows WebView2，验证录入、完整税表查询、人工选择和模板导出，结果写入系统临时目录。

反馈问题时请提供 Git 提交号或程序包下载日期、操作步骤和匿名商品样例，不上传真实发票、企业资料或本地配置。

参与开发时，请保持标准模板字段含义、历史文件只读和人工选择优先。公开提交只包含源码、测试、构建配置、必要资源及使用说明，内部计划、工作记录和本地配置保留在本地。代码采用 MIT 许可证，内置资料的适用范围见 [资源说明](docs/RESOURCES.md)。
