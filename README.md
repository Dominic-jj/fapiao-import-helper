# 发票明细导入助手 · 电子税务局商品录入与 Excel 导入

在本地快速输入商品，搜索并确认商品税收分类编码，导出标准 Excel，再通过电子税务局的“明细导入”一次导入整张清单。Windows 桌面工具，原项目名称 FasterTax，代码采用 [MIT 许可证](LICENSE)。

**快速输入 → 校对并确认税编 → 导出 Excel → 官方明细导入。** 实际发票开具与打印仍在官方系统完成。

## 下载与启动

[版本说明](docs/RELEASE_NOTES.md) · [下载页面](https://github.com/Dominic-jj/fapiao-import-helper/releases)。当前为预览阶段，暂无正式 Release 安装包；实际官方明细导入验收完成后再发布。

Windows 程序包解压后运行整个目录中的 `FapiaoImportHelper.exe`，无需 Python。目标电脑需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。请保留同目录的 `_internal` 文件夹。

## 为什么做这个工具

项目作者在广东省电子税务局开票时遇到商品较多导致的录入卡顿、分类难找，以及官方页面关闭后丢失输入的问题。本工具利用已有的 Excel 明细导入功能，将重复录入和税编选择放到本地完成。

- 每行快速打字，支持省略规格、Tab/CSV 粘贴，Ctrl+Enter 解析。
- 名称、规格、单位、数量、单价和税率可编辑，金额自动重算。
- 搜索商品分类、简称、说明或编码，方向键切换候选，Enter 选择，Esc 关闭。
- “浏览税编表”按大类和分类路径查询完整本地税表，分页浏览、查看完整说明和复制具体税号；从明细行进入可直接确认并应用。
- 自动建议需要确认后才能导出和保存；人工选择在重新匹配时保留。
- 输入和有效编辑自动保存本地草稿，启动恢复；税表变化时重新核对分类。
- 自选历史商品目录，个人确认库优先，原始历史只读，同名不同属性记录分别保留。
- 默认通用模式，五金/电工/水暖词库可选；AI 默认关闭，支持按需辅助。

## 三步准备明细

### 1. 快速输入

```text
笔记本 本 5 8
A4 复印纸 包 2 25
漏电开关 个 1 65
```

按“名称 单位 数量 单价”逐行输入，有规格时放在名称之前，例如 `2x63A 漏电开关 个 1 100`。从右往左读取单价、数量和单位，再识别规格；无规格无需占位符。

从 Excel 复制时，四列为“名称、单位、数量、单价”，五列为“名称、规格、单位、数量、单价”。空规格列保留，金额由系统重算。按 Ctrl+Enter 或“解析明细”进入表格校对。

### 2. 校对并确认商品税编

核对数量、单价、规格和金额。在税编搜索框输入商品或分类名称、简称、编码，选择最符合实际商品的具体分类；自动建议需点击“确认建议”。信息不足时补充规格或手动搜索，程序不猜测材质、用途或税率。

“保存税编确认”只保存已确认记录，下次相同名称与兼容属性可复用。修改名称重新匹配，规格/单位变化更新自动建议，人工选择保留并提示核对，数量/单价变化只重算金额。

搜索候选不满意时，点击页面顶部“浏览税编表”或该行“浏览表”。左侧选择大类，中间点击“查看下级”逐级浏览，右侧查看完整分类说明。支持按名称、简称、说明或编码搜索当前分类及下级，返回“全部分类”即可搜索全表。“只看可选商品”隐藏汇总项；汇总分类不可应用。选择具体商品后可复制税号，或指定明细行并点击“确认并应用到这一行”。

### 3. 设置口径并导出 Excel

在“我的商品库与导出设置”中核对默认税率和含税/不含税单价口径；默认税率用于新明细，已有行可以逐行修改。程序保留原单价口径，官方导入时须选择相同选项。

未确认或无效税编、非法数字及未解析行会阻止导出。导出前提交表格的最新编辑，生成标准 `.xlsx` 文件。文件用于官方批量导入。

## 在官方系统导入

以下截图由用户提供，仅说明广东页面的操作位置，界面可能更新；输入面板已裁剪，公开副本不含原图中的企业资料。本工具为独立第三方本地助手。

登录广东省电子税务局，进入蓝字发票开具页面。

![广东省电子税务局官方首页](resources/screenshots/official-home.png)

在开票信息区域点击红圈标出的“明细导入”。

![官方开票信息区域及明细导入按钮](resources/screenshots/official-entry-panel.png)

点击“选择文件”，选择刚导出的 Excel，设置相同的含税/不含税口径，检查行数、商品编码、金额和税率，成功后确认导入，再完成官方开具和打印。

![官方明细导入面板及选择文件入口](resources/screenshots/official-detail-import.png)

当前代码保留项目现有模板结构；本次尚未验证真实官方上传，不宣称已经兼容所有地区或模板版本。模板与税表来源说明见 [资源说明](docs/RESOURCES.md)。

## 我的商品库与草稿

在“我的商品库与导出设置”选择自己的历史目录，保存后立即读取，启动时自动加载。页面显示文件数、记录数、冲突与忽略原因；目录失效不阻止手动录入。可使用“打开目录”查看原始文件。

首种支持格式是项目现有标准明细模板：工作表 `1-明细模板`，第 3 行标准表头，第 4 行开始，A/B/C/D 列为名称、税编、规格和单位。其他格式会跳过并说明原因，不随意读取活动 sheet。

历史是本地查表，未训练模型。普通历史先作为建议，人工确认并保存后才成为可复用确认。不同属性和冲突编码保留；明确的尺寸差异可兼容，未知型号差异仍需核对。

源码和打包版的可写数据使用 `%LOCALAPPDATA%\FasterTax\`，为兼容旧版本保留这个目录名。草稿与偏好保存在该目录，确认映射保存在 `resources/mappings/`。旧源码目录里的真实映射首次迁移时只复制，不覆盖已有用户数据；旧历史目录继续兼容读取，自选目录后以用户选择为准。

公共包仅包含页面、模板、税表和公共词库，作者个人历史、映射、配置、原始截图和密钥不进入公共包。用户的 `tmp/` 和原文件保留在本地。

## 可选 AI

录入、搜索、确认和导出完整支持本地运行。AI 默认关闭，配置后对待确认行点击“AI 找候选”；网络等待不会持有录入锁，可取消结果应用。AI 建议仍需人工确认。

启用会将商品名称、规格、单位及候选信息发送给 DeepSeek。用户自行提供 API Key，应用内配置的密钥存入系统凭据管理器，也可使用 `DEEPSEEK_API_KEY` 环境变量。关闭或调用失败不会影响本地流程。取消无法撤回已经发送的网络请求，但会丢弃返回结果。

源码安装 `python -m pip install -e '.[ai]'` 可使用 AI；默认公共构建不包含 AI SDK，可选构建方式见下文。AI 结果仍须按真实商品核对并由用户确认。

## 开发者运行

Windows 10/11、Python 3.10+：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

## 构建 Windows 包

```powershell
python -m pip install -e '.[build]'
python -m PyInstaller --noconfirm --clean --distpath output/dist --workpath output/build packaging/FasterTax.spec
```

产物为 `output/dist/FapiaoImportHelper/FapiaoImportHelper.exe`，分发完整程序目录。含可选 AI SDK 时安装 `.[build,ai]` 并设置 `$env:FASTER_TAX_BUILD_AI = '1'` 后执行同一构建命令。
