# 版本说明

## 0.2.1 · 预览阶段

- 新增“浏览税编表”：按大类与分类路径逐级查看完整本地税表。
- 支持名称、分类简称、说明和编码搜索，分页显示，并可只看具体商品。
- 显示完整分类说明与编码；汇总分类只能查看，具体商品可复制税号或确认到明细行。

## 0.2.0 · 桌面基础功能

- 快速逐行录入、表格校对和标准 Excel 导出。
- 商品税编搜索、人工确认、确认库复用和可选行业词库。
- 自选历史商品目录、草稿自动保存与恢复。
- 默认税率、逐行税率和含税/不含税价格口径设置。
- 可选的按需 AI 找候选，默认关闭。

正式 Windows 包尚未发布，仍待实际官方明细导入验收。适用模板及资源说明见 [RESOURCES.md](RESOURCES.md)。
